- [ ] 树莓派完整工程能够一条launch命令启动。
- [ ] 小程序可以完成建模、预览、启动、暂停、恢复和取消。
- [ ] RTK固定解下车辆能够完成多段往复式清扫。
- [ ] 下位机命令、ACK、完成状态和重连安全链路通过真机验证。
- [ ] 正常触边、异常触边、RTK丢失和急停均有明确且安全的处理结果。
- [ ] 模型、系统配置和必要记录重启后能够正确恢复。
